# multilayer_perceptron

## Overview

Parameters for scikit-learn's multilayer perceptron classifier. The default pipeline standardizes features. `MultilayerPerceptronActivation` and `MultilayerPerceptronSolver` live in `classreg.options` and are re-exported here.
