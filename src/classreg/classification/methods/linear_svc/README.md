# linear_svc

## Overview

Parameters for scikit-learn `LinearSVC`, a linear support vector classifier. The default pipeline standardizes features, and the processor exposes margins rather than probabilities.

## Components

| Component | Description |
|-----------|-------------|
| [parameter.py](./parameter.py) | `LinearSVCParameters`. |
| [penalty.py](./penalty.py) | `LinearSVCPenalty` enum. |
| [loss.py](./loss.py) | `LinearSVCLoss` enum. |
