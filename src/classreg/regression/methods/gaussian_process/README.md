# gaussian_process

## Overview

Parameters for scikit-learn `GaussianProcessRegressor`. The default pipeline standardizes features and normalizes targets. Training time grows with the cube of the number of samples. `GaussianProcessKernel` lives in `classreg.options` and is re-exported here.
