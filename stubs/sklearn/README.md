# sklearn

## Overview

Type stubs for the parts of scikit-learn that `classreg` uses, so that mypy and basedpyright check calls into it. Each stub module mirrors the scikit-learn module of the same name.

## Components

| Component | Description |
|-----------|-------------|
| [compose.pyi](./compose.pyi) | Target-transforming regressor wrapper. |
| [cross_decomposition.pyi](./cross_decomposition.pyi) | Partial least squares. |
| [datasets.pyi](./datasets.pyi) | Bundled datasets used in tests. |
| [discriminant_analysis.pyi](./discriminant_analysis.pyi) | Linear and quadratic discriminant analysis. |
| [dummy.pyi](./dummy.pyi) | Dummy classifier and regressor. |
| [ensemble.pyi](./ensemble.pyi) | Tree, boosting, bagging, stacking, and voting ensembles. |
| [isotonic.pyi](./isotonic.pyi) | Isotonic regression. |
| [kernel_ridge.pyi](./kernel_ridge.pyi) | Kernel ridge regression. |
| [linear_model.pyi](./linear_model.pyi) | Linear and generalized linear models. |
| [metrics.pyi](./metrics.pyi) | Classification and regression metrics. |
| [naive_bayes.pyi](./naive_bayes.pyi) | Naive Bayes classifiers. |
| [neighbors.pyi](./neighbors.pyi) | Nearest neighbor estimators. |
| [neural_network.pyi](./neural_network.pyi) | Multilayer perceptrons. |
| [pipeline.pyi](./pipeline.pyi) | Pipelines. |
| [preprocessing.pyi](./preprocessing.pyi) | Feature scalers. |
| [svm.pyi](./svm.pyi) | Support vector machines. |
| [tree.pyi](./tree.pyi) | Decision trees and extra trees. |
| [exceptions/](./exceptions/README.md) | Exceptions and warnings. |
| [gaussian_process/](./gaussian_process/README.md) | Gaussian process estimators and kernels. |
